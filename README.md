# toukei_tashikame

技術同人誌『Pythonで学ぶ！統計学入門 — シミュレーションで確かめる、推定・検定・回帰・ベイズ・因果推論』の教材リポジトリ。

名前は本書の方法そのものから取っている。**回して数えて確かめる。** 95%信頼区間の95%が何を意味するかは、定義文を10回読むより 10,000 回回して `0.9502` を見るほうが速い。その 10,000 回を、読者の手元で実際に回せる形にしたものがこのリポジトリである。

## 3つの約束

| # | 約束 | 意味するところ |
|---|---|---|
| 1 | **全スクリプトが単体で実行できる** | `uv run python examples/ch07/pvalue_is_uniform.py` だけで動く。前の節のスクリプトを先に走らせる必要はない。データのダウンロードも不要 |
| 2 | **同じ数字が出る** | すべての生成器が `seed` を取り、`np.random.default_rng` だけを使う。`np.random.seed` は一度も呼ばない |
| 3 | **本文の数字はここから出る** | 本に印刷された数値は `tests/test_book_numbers.py` が回帰テストとして固定している |

## 使い方

```bash
git clone https://github.com/ykus4/toukei_tashikame
cd toukei_tashikame
uv sync                       # Python 3.12 と依存が入る
uv run python examples/ch06/coverage_is_about_intervals.py
# -> 0.9502 ± 0.0043
```

第16章（MCMC / PyMC）と第18-4節の計5本だけは追加の依存が要る。

```bash
uv sync --extra slow
```

### `examples/` と `notebooks/` の違い

`examples/` が本文の正典で、本に載るコードブロックはここからの抜粋。CI で毎回全部実行する。`notebooks/` は読者の遊び場で、CI では実行しない。**ノートブックが壊れても本は壊れない**、という非対称を意図的に作ってある。

## 設計で外していないこと

**真値を返り値に持つ。** 被覆確率も第一種の誤りも、真値を知らなければ数えられない。実データで信頼区間の当たり外れを数えられないのは道具の限界ではなく、真値が隠れているという状況そのものの帰結である。合成データだけが持っている情報を、返り値のかたちで明示している。

```python
d = datasets.ab_test(p_a=0.030, lift=0.10, seed=0)
d.p_b        # 0.033 — 合成データだけが知っている真値
d.b.mean()   # 観測されたCVR。推定の対象であって、答えではない
```

**シミュレーション自体の誤差を併記する。** `sim.coverage` と `sim.rejection_rate` は `.se` を返す。`0.9502` と `0.9487` の違いを実装の差だと誤解させないための装置で、10,000回なら 95% 付近で ±0.0043 程度は数え直すだけで動く。

**色は役割で決まる。** `plots.PALETTE` を役割名で引く。真値は赤の実線、推定は青、棄却域はオレンジの塗り。呼び出し側で色を選ばない。
